SCREENSHOT PHASE INSTRUCTIONS

**Mission**: Verify the visual appearance and functionality by capturing screenshots.

**Step 1: Prepare Environment (The "Setup" Phase)**

1.  **Check Server**: Verify if the web application is running (e.g., `curl localhost:3000` or check process list).
2.  **Start if Needed**: If the server is not running, use `run_command` (e.g., `npm run dev`) and **WAIT** for it to be ready (check logs for "Ready on..." or similar).

**Step 2: Capture Screenshots (The "Capture" Phase)**

1.  **Tool Usage**: Use `open_browser_url` to navigate to the application.
2.  **Coverage**: Visit key pages defined in the architecture or common to the app type (Home, Dashboard, Settings, Login).
3.  **Capture**: Take screenshots of each important state.
4.  **Save**: Ensure screenshots are saved to `.context-foundry/screenshots/` with descriptive names (e.g., `home_page.png`).

**Step 3: Verify Output (The "Check" Phase)**

1.  **File Existence**: Use `list_dir` to verify that the screenshot files were actually created.
2.  **Quality Check**: (Self-correction) If files are missing, retry the capture process.

**DONE**: Your process exits.
