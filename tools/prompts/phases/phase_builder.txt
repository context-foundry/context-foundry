```json
{

      "task_id": "task-1",
      "name": "Core Module",

        "mkdir -p src",

        "cat > src/core.py << 'EOF'\n# Core implementation\nEOF"
      ]
    },
    {
      "task_id": "task-2",
      "name": "Utilities",
      "description": "Create utility functions",
      "working_directory": ".",
      "files": ["src/utils.py"],
      "dependencies": [],
      "build_commands": [
        "mkdir -p src",
        "cat > src/utils.py << 'EOF'\n# Utility functions\nEOF"
      ]
    },
    {
      "task_id": "task-3",
      "name": "Main Entry Point",
      "description": "Create main entry",
      "working_directory": ".",
      "files": ["src/main.py"],
      "dependencies": ["task-1", "task-2"],
      "build_commands": [
        "cat > src/main.py << 'EOF'\n# Main entry point\nfrom src.core import *\nfrom src.utils import *\nEOF"
      ]
    }
  ]
}
```

**IMPORTANT:** Each task MUST include:
- `task_id` (string): Unique task identifier
- `name` (string): Human-readable task name
- `description` (string): What this task does
- `working_directory` (string): Directory to run commands in (usually ".")
- `files` (array): List of files this task creates
- `dependencies` (array): Task IDs this task depends on
- `build_commands` (array): Shell commands to execute for this task

🎯 BUILDING PROCESS FOR FLOWISE
═══════════════════════════════════════════════════════════

1. **Load Flowise Pattern Library**:
   - After `build-tasks.json` exists, read every JSON file inside `<context_foundry_root>/extensions/flowise/patterns/`
   - Use these pattern files as your template for node structure

2. **Check for Matching Example Flows** (HIGHLY RECOMMENDED):
   - Determine the workflow pattern type from architecture.md (Routing, Parallel, Sequential, Conditional, Loop, Hybrid)
   - Check `<context_foundry_root>/extensions/flowise/examples/{pattern-type}/` for working example flows
   - If matching examples exist:
     - **Read the example JSON file** - it's a complete, production-quality flow
     - **Use it as your primary template** - copy the structure, node types, connections
     - **Adapt the content** - change agent personas, routing logic, tools to match your requirements
     - **Keep the proven pattern** - don't reinvent validated structures
   - If no examples exist for your pattern type:
     - Use the general patterns from step 1 and templates from step 3
     - Consider contributing your flow as an example after successful build!

   **Example pattern types:**
   - **routing/** - Intent-based routing with ConditionAgent or LLM classifier
   - **parallel/** - Concurrent execution with result merging
   - **sequential/** - Multi-step chaining workflows
   - **conditional/** - Decision tree branching
   - **loop/** - Iteration and batch processing
   - **hybrid/** - Mixed patterns for complex workflows

3. **Read Templates**:
   - Read template files from `extensions/flowise/prompts/*.json`
   - Copy COMPLETE structures, not abbreviated versions

3. **Build Each Node Type**:
   - **Start Node**: Use startAgentflow template with inputParams
   - **Agent Nodes**: Copy FULL inputParams array (~90 lines)
   - **ConditionAgent**: Include scenarios array with display flags
   - **DirectReply**: Include inputParams with display flag

4. **Customize Only the inputs Object**:
   - inputParams defines the SCHEMA (never modify)
   - inputs holds the ACTUAL VALUES (customize this)

5. **Validate Structure**:
   - Each agent node should be 150-200 lines
   - Total flow should be 1500-2500+ lines (NOT 400)
   - All nodes have color, baseClasses, category, description

1. ❌ Missing inputParams array entirely
2. ❌ agentMessages as string instead of array
3. ❌ Missing agentSelectedToolConfig in tools
4. ❌ No color/baseClasses/category/description
5. ❌ Missing width/height/positionAbsolute
6. ❌ Abbreviated node structures (<100 lines per agent)
7. ❌ Generic field names (model instead of agentModel)
8. ❌ Missing version field (must be 2.2 for agents)

**Quick Validation**:
- Generated flow < 1000 lines? WRONG - rebuild with complete structures
- Agent nodes < 100 lines? WRONG - missing inputParams
- No inputParams array? WRONG - nodes won't render in UI
