SCOUT PHASE INSTRUCTIONS

**Step 1: Research Task Requirements**

Use `/agents` command to create a Scout sub-agent:
```
Type: /agents
Description: "Expert researcher who gathers requirements, explores codebases, analyzes constraints, and provides comprehensive context for implementation. All research findings must be consolidated into a single concise summary (10-20KB). Do NOT create separate research documents."
```

Research:
- Analyze task requirements thoroughly
- Explore existing files in working directory
- Identify technology stack and constraints
- Research best practices for this project type
- Document challenges and recommended solutions
- Identify testing requirements

**API Integration Research** (if project uses external APIs):
- Research API's CORS policy
- Check if "Server-side only" or requires API key in headers
- If API blocks CORS: Flag need for backend proxy

**Step 2: Save Scout Report**

Use the Write tool to create `.context-foundry/scout-report.md`:

```markdown
# Scout Report: {Project Name}

## Executive Summary
{2-3 paragraphs - what is being built and why}

## Key Requirements
- {Requirement 1}
- {Requirement 2}
- {Requirement 3}

## Technology Stack
**Backend**: {stack with brief justification}
**Frontend**: {stack with brief justification}
**Database**: {choice with brief justification}
**Testing**: {approach}

## Architecture Recommendations
1. {Top recommendation}
2. {Second recommendation}
3. {Third recommendation}

## Challenges & Mitigations
1. **Challenge**: {issue}
   **Mitigation**: {solution}

## Testing Approach
- {Testing strategy 1}
- {Testing strategy 2}
```

Keep report concise: 10-20KB, NOT 60KB+

**Step 3: Cleanup Extra Files**

Remove any extra research documents:
```bash
rm -f RESEARCH_FINDINGS.md API_RESPONSE_EXAMPLES.md EXECUTIVE_SUMMARY.md 2>/dev/null || true
```

**Step 4: Verify Output**

```bash
ls -la .context-foundry/scout-report.md && echo "FILE EXISTS" || echo "FILE MISSING"
```

**DONE**: Scout phase complete. Your process will exit, releasing context.
