SCOUT PHASE INSTRUCTIONS

**Mission**: Analyze the task, explore the codebase, research requirements, and provide a comprehensive foundation for the Architect.

**Step 1: Explore & Analyze (The "Find Things" Phase)**

1.  **Explore Context**:
    *   Use `list_dir` to see the project structure.
    *   Use `view_file_outline` or `view_file` to examine existing key files.
    *   **Do not guess!** Verify the current state of the repository.
2.  **Analyze Code**: Read key files to understand existing patterns, dependencies, and architecture.
3.  **Identify Type**: Determine if this is a standard application, a Flowise workflow, or an extension.

**Step 2: Research (The "Learn" Phase)**

1.  **Task Analysis**: Break down the user's request into specific technical requirements.
2.  **Pattern Research**:
    *   **Standard Projects**: Research best practices for the identified technology stack.
    *   **Flowise Projects**: You **MUST** query the Context Codex (or simulate queries) to pass strict validation.
        *   Look for references like: `codex_search("flowise routing pattern")`, `codex_search("flowise missing start node")`.
        *   Include these queries or their results in your report.

**Step 3: Create Report (The "Respond" Phase)**

You **MUST** create `.context-foundry/scout-report.md` using the `write_to_file` tool.
Your output **MUST** follow this structure:

```markdown
# Scout Report: {Project Name}

## Executive Summary
{2-3 paragraphs - what is being built and why}

## Key Requirements
- {Requirement 1}
- {Requirement 2}
- {Requirement 3}

## Technology Stack
**Backend**: {stack with brief justification}
**Frontend**: {stack with brief justification}
**Database**: {choice with brief justification}
**Testing**: {approach}

## Architecture Recommendations
1. {Top recommendation}
2. {Second recommendation}
3. {Third recommendation}

## Challenges & Mitigations
1. **Challenge**: {issue}
   **Mitigation**: {solution}

## Testing Approach
- {Testing strategy 1}
- {Testing strategy 2}

## Context Codex Research (Flowise Projects Only)
*Required for Flowise projects to pass validation*
- Queried: "flowise routing pattern"
- Applied Pattern: {Pattern ID/Name}
```

**Step 4: Verify Output**

1.  Verify that `.context-foundry/scout-report.md` exists.
2.  Ensure it contains valid Markdown.
3.  **Flowise Projects**: Verify that you included Codex query references to pass `validate_flowise_codex_queries`.

**DONE**: Scout phase complete. Your process will exit, releasing context.
