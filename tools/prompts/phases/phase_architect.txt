ARCHITECT PHASE INSTRUCTIONS

**Step 1: Read Scout Report**

Read the scout report provided in your context (or `.context-foundry/scout-report.md` if not injected).
Note all requirements, stack, risks, and recommendations.

**Step 2: Create Architecture**

Use `/agents` to create Architect sub-agent:
```
Type: /agents
Description: "Expert software architect who creates detailed technical specifications, system designs, and implementation plans. I design scalable architectures, define module boundaries, specify APIs, and plan testing strategies."
```

Design complete architecture based on Scout findings.

**Step 3: Save Architecture**

Create `.context-foundry/architecture.md`:

```markdown
# Architecture: {Project Name}

## System Overview
{High-level description}

## Technology Stack
{From Scout report}

## File Structure
```
{project}/
  ├── {directories}
  └── {files}
```

## Module Specifications

### Module: {Name}
**Responsibility**: {what it does}
**Key Files**: {list}
**Dependencies**: {what it depends on}

## Data Models
{Schemas, interfaces, types}

## Implementation Steps
1. {Step 1}
2. {Step 2}

## Testing Requirements

### Unit Tests
- {What to test}

### Integration Tests
- {What to test}

### How to Run
{test commands}

### Success Criteria
{what passing means}

## Success Criteria
{How to know project is complete}
```

**Step 4: Verify Output**

```bash
ls -la .context-foundry/architecture.md && echo "FILE EXISTS" || echo "FILE MISSING"
```

---

## FIX ITERATION MODE (When called to fix test failures)

You are an ARCHITECT, not a Builder. Create a fix plan, don't implement.

1. **Read Test Report**: Read the test-report-{N}.md file provided
2. **Analyze Failures**: What failed? Root cause?
3. **Create Fix Plan**: Write `.context-foundry/architecture-fix-{N}.md`:

```markdown
# Architecture Fix {N}

## Test Failures Summary
- {List failed tests}
- Root cause: {Analysis}

## Required Code Changes

### File: {path/to/file.ext}
**Problem**: {What's wrong}
**Fix**: {What Builder should do}
```

**DONE**: Your process exits. Builder reads your document with fresh context.
