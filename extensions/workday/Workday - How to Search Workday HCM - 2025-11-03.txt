Welcome to Workday HCM search. In this session, we'll identify and demonstrate the search functionality in Workday. Workday has many different search features that allow you to efficiently navigate the platform. These features include the search bar, search field prompts, and search reports.

Global search is the core navigation tool within Workday. Use the search bar in the header to search for tasks, reports, business objects, and more. For an efficient experience, Workday uses the following functionalities to provide you with the most accurate search results:

- **Search categories** allow you to prioritize and order the most relevant search results when you enter a term or phrase in the search bar and select enter.
- **Predictive searches** provide you with the best match search results with minimal typing. Enter at least three characters to display predictive suggestions.
- **Prefix searches** quickly narrow search results by restricting them to a specific Workday object.

There are many ways to search in Workday, and it's important to understand the different ways to navigate to data. Similar to global search, you can use search field prompts throughout Workday. You often use this type of search when the system displays a prompt to search for existing information and help you navigate search fields. Search field prompts display different folders with all the available content in relation to that field.

There are two ways to use this search type. The first is to select each relevant folder until you find the item that you're searching for. Alternatively, you can enter a search term in the field. The system then searches against the data applicable to that selection to narrow the results. At times, the prompt field displays a prompt list icon. This is a single-select field where you can only select one value from the prompt list. The list will no longer display after you select a value. However, if the prompt list continues to display, then the field is multi-select, and you can select one or more values from the prompt list as necessary. The field will expand as you select additional values. Select the "X" to remove any values from the list.

Now, let's discuss search reports. You can narrow and organize large groups of data in search reports by sorting and applying filters. For example, the "Find Workers" report allows you to locate active workers by the values defined by your organization. Search reports operate on a specific data source and contain three sections: the results, the search bar, and the defined filters.

The results section contains the results of the search report. By default, Workday displays the entire data set. Use the search bar or the given values to narrow the results. Located at the top of the report, enter a term or phrase in the search bar to narrow the search results from the data set. Filters display on the left side, and each category contains one or more values. Locate different categories and select key values to filter the results.

You can reuse search report results by creating a saved search. Use saved searches to access a specific data set at a future time or to complete other tasks. To save search results, select the save button and enter a corresponding name. You can access all of your saved searches below the search bar. It's important to note that only you can access your saved searches, and they are not available to other workers.
