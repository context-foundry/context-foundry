Welcome to Workday Learning: Enhance media files and create lessons. In this session, we'll discuss and demonstrate how to update media files and create lessons to meet your business requirements.

Workday Learning makes content creation effortless with the integration of Media Cloud, which is included with your Workday Learning subscription. You can enhance your media by adding interactions, transcriptions, and captions. You can also customize playback settings. Then, you can seamlessly incorporate these enriched media files into standalone lessons for your workforce.

Let's explore how Workday Learning and Media Cloud empower you to elevate your learning content. Media Cloud seamlessly integrates with Workday Drive, providing instant access to your media files. This integration allows you to store, collaborate, and enhance your media files, enabling you to build dynamic and engaging lessons. Media Cloud is compatible with many different file types to create learning content, including images, documents, video, audio, and more. Workday Drive also allows you to set security permissions to share and restrict these files with others in your organization.

Media Cloud empowers you to enhance media files with interactions, captions, and transcriptions, as well as set playback options, streamlining your content creation process. Before enhancing a media file, Workday recommends making a copy of the original file in Workday Drive.

In this example, Mark Navaro, the director of sales operations in Chicago, updates a media file with interactions for his sales team. To begin, Mark locates and copies the "Make Good Impression" media file. After giving the copied file a unique name, he opens the file and selects the edit media button. From the edit media panel, Mark selects the interactions tab to open the interactions panel.

The interactions panel offers a variety of video interactions you can add to a media file, including multiple-choice questions, text notes, open responses, and checkbox questions. You can add these interactions individually or stack them together to test learner knowledge, gather opinions, or collect learner acknowledgments. To add an interaction, Mark can either select the desired time directly on the play bar or manually enter the time in the upper right corner of the interactions panel.

Next, in the interactions panel, he selects the type of interaction. In this example, Mark selects the multiple-choice option. Notice how the interactions panel dynamically updates, allowing him to enter his question in the text box. Below the text box, he can add the number of required answer choices to meet his business needs. Mark selects the pull-down menu to designate whether each answer choice is correct, incorrect, or unscored. Finally, Mark selects the add button to add the interaction to the media file. You can repeat this process when adding any multiple-choice or checkbox interaction to a media file.

Now, Mark adds an open response interaction. Again, he selects the desired time and then selects the open response interaction option. From the open response panel, Mark creates an acknowledgment for the learner to attest that they viewed the media file. Finally, he selects the add button to complete this interaction. You can repeat this process for any open response or text note interactions.

Media Cloud also enables video caption and transcription files. When you select the captions tab in the edit media panel, Media Cloud automatically converts the audio file into a VTT file using machine learning. You can download this file or upload additional transcription files. To upload a VTT file, you can either drag and drop the file into the upload box or use the select file link to choose a file from your desktop. Once you upload the file, you can select the applicable transcription language. You can upload an unlimited number of transcription files to a single media file.

Finally, from the settings tab, you can set different playback settings to customize a media file. The skip restrictions checkbox prohibits learners from skipping forward; however, learners can rewatch previously viewed segments. The limit question attempts checkbox limits the learner to answering a set of interactions once, while the passing score checkbox determines the percentage of questions the viewer must answer correctly to pass or meet the lesson requirements. Both of these playback settings are contingent on whether interactions exist on the media file. Lastly, the restrict access checkbox will restrict media file access, but this option is only available when an authentication policy exists in Workday Learning. Media Cloud allows you to decide which playback settings to leverage to customize each media file.

Once you finish enhancing a media file, you can preview these changes. From the edit media page, select the preview icon, which looks like an eye, in the upper left corner of the video. This allows you to experience the media as a learner, including completing any interactions, captions, and transcriptions in different languages. When the media file meets your requirements, select the publish button or the save draft button to continue at a later time. Mark selects the publish button, which saves the current version of the media file. You can also select the revert button to clear any enhancements made to the media file since your last save.

Workday Learning tracks learner responses to interactions within media files. While Workday does not deliver a standard report, you can create a custom report tailored to your specific requirements. This allows you to gather valuable insights into learner performance.

Now, let's discuss how workers can access and consume these media files. Workday Learning allows you to use a single media file, excluding packaged content, to build standalone lessons. For packaged content, you can use other learning components such as courses. Learners can access this learning component on demand without needing to enroll. Keep in mind that each lesson requires a unique name and media file.

When creating a lesson, Workday recommends focusing on a single subject, such as a recording, demonstration, job aid, or video, as you are limited to one file per lesson. The content creation approach in Workday Learning transforms learning and development into a collaborative process where anyone in your organization can create standalone lessons. This empowers employees to easily share vital knowledge with their colleagues, ensuring that institutional knowledge stays within their organization.

In this example, Mark will use the "Make Good Impressions" interactions media file to create a standalone lesson for his sales team. Mark starts by using the create lesson task. On the create lesson page in the lesson details section, Mark enters a unique title and description and designates a topic. Next, in the media section, Mark adds an optional cover image. He selects the select file button and then Drive to select the "Make Good Impressions" interactions media file. Once Workday scans for any viruses, Mark selects submit. Now the lesson is available in the learning catalog for all workers, including Julia Brandt, a sales compensation analyst on Mark's team. Julia uses the browse learning content report and filters by the created by worker facet to locate and consume the lesson.

Standalone lessons offer even greater flexibility as you can distribute them through learning campaigns and mass enrollments. This allows you to efficiently distribute and track training materials, ensuring your workforce stays informed and aligned with organizational goals.

In this session, we've learned how to enhance a media file with interactions, captions, and transcriptions. We've also explored how to customize playback options. Finally, we have learned how to use these enriched media files to build engaging standalone lessons for your workforce. Thank you for taking the time to learn with Workday.
