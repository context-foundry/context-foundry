### BUILDER PHASE INJECTION

# === ROBLOX-BUILDER-START ===
**LUAU CODE IMPLEMENTATION**

If CONFIGURATION shows roblox_project: True:

⚡ **BUILDING ROBLOX GAME CODE** ⚡

**Language:** Luau (typed Lua), NOT JavaScript/Python/TypeScript
**File Extension:** .lua
**Runtime:** Roblox engine

**CRITICAL SECURITY RULES:**

1. **ALWAYS Validate RemoteEvent Payloads:**
```lua
RemoteEvent.OnServerEvent:Connect(function(player, amount)
    -- Type validation
    if type(amount) ~= "number" then return end

    -- Range validation
    if amount < 0 or amount > 1000000 then return end

    -- Business logic validation
    if amount <= getPlayerBalance(player) then
        processRequest(player, amount)
    end
end)
```

2. **Server-Authoritative Logic:**
- ❌ Client: "Give me 100 coins" (exploitable)
- ✅ Client: "I collected this coin" → Server validates & awards

3. **DataStore Pattern:**
```lua
-- Always use pcall + retry logic
for attempt = 1, 3 do
    local success, result = pcall(function()
        return DataStore:UpdateAsync(userId, updateFunction)
    end)
    if success then return result end
    wait(2 ^ attempt)  -- Exponential backoff
end
```

**Coding Standards:**
- Use type annotations: `local function foo(x: number): string`
- Return frozen tables: `return table.freeze(Module)`
- Cache services: `local Players = game:GetService("Players")`
- Wrap DataStore in pcall
- Disconnect events when done
