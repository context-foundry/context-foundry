# Basic Obby Template

This is a reference template for a basic Roblox obby game with checkpoints and a coin shop.

## Features

- Checkpoint system with progress saving
- Coin collection and persistence
- Shop system
- DataStore integration
- Server-authoritative architecture

## Building

```bash
rojo build default.project.json -o dist/Game.rbxlx
```

## Structure

This template demonstrates the recommended structure for Roblox games built with Context Foundry.

See main project README for full documentation.
