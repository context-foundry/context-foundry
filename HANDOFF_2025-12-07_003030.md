## How Things Work

### Dashboard ↔ Daemon Communication
- Dashboard runs on port 5174 (Vite dev) or served by daemon
- API calls go to port 8421 (daemon HTTP API)
- Vite proxy config in `tools/dashboard/vite.config.ts`

### Sidekick Chat Flow
1. User types message in chat input
2. Frontend calls `POST /api/sidekick-chat`
3. Backend uses Claude CLI (haiku model) for response
4. If response contains `[[START_BUILD:...]]`, submits job to JobManager

### Job Display
- Jobs fetched via `GET /api/jobs`
- Polling every 3 seconds (SSE not yet implemented)
- Duration counter updates via `setInterval` in React
