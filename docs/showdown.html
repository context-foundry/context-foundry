The Verdict

Context Foundry

Best for: The lone wolf who wants AI that learns

Solo developer running tasks through a disciplined pipeline. Every completed job teaches the system something new. Pattern matching gets sharper, doubt gets smarter, wasted cycles get fewer. If you believe agents should improve with use, not just execute, this is your horse.

Citadel

Best for: The campaign trail rider who watches every dollar

You have a multi-day feature to build and you want the cheapest path through it. Zero-token routing handles the easy stuff. Campaign files survive session crashes. Eight hooks enforce quality without you watching. If cost-per-task matters and you live in Claude Code, saddle up here.

Gas City

Best for: The railroad baron running a fleet

You have 20+ agents across multiple repos and you need them coordinated, monitored, and attributed. Health patrols, merge queues, federated networks. If you are building agent infrastructure for a team or an organization, this is the only framework at the table built for that scale.
