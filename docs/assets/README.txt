
Context Foundry – GitHub Image Pack
===================================

Files:
- cf-logo-transparent-2048.png — Base transparent logo for general use.
- avatar-dark-512.png / avatar-light-512.png — GitHub org/repo avatar (512×512).
- avatar-dark-1024.png / avatar-light-1024.png — Hi‑res avatars (1024×1024).
- icon-256.png — Square transparent icon.
- favicon.ico — Multi‑size favicon (16/32/48/64 px).
- social-card-1280x640-*.png — Open Graph images (GitHub social preview).
- social-card-1280x640-*-text.png — Same with simple tagline text.
- banner-1280x320-*.png — README header banner.

Suggested uses on GitHub:
- Organization or repo avatar: upload `avatar-dark-512.png` (or the light variant for white UI).
- Social preview (Settings → Social preview): upload `social-card-1280x640-dark.png`.
- README banner: reference `banner-1280x320-dark.png` at the top of README.md.
- Favicon: for docs sites or Pages, use `favicon.ico`.
